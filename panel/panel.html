快捷说明

部署方式：Argo 隧道（默认）或直连节点，两种可以一起装；协议各自勾选，只装选中的。订阅统一拉取隧道节点（裂变后）和直连节点（原样），一个订阅里全有。裂变请用订阅生成器或其它工具手动完成，本面板不做裂变。

部署安装

填好设置，点「开始部署」，面板在 VPS 上自动完成部署。部署日志和检查结果在下方查看。带 * 必填 的是必填项，带 选填 的可留空。

① 部署方式

Argo 为默认；直连会暴露 VPS 真实 IP，仅作备用。两种可以一起装。隧道节点和直连节点共用一个域名会同时暴露两种入口，请使用不同的子域名。

② 协议选择

隧道协议与直连协议在同一处勾选，只部署选中的协议；每条协议后面都有自己的端口设置。只勾一种方式时，只显示那种方式的协议。

③ 配置参数

直连配置

直连会暴露 VPS 真实 IP，仅作备用；请使用与隧道节点不同的子域名。

留空用 VPS 公网 IP。

直连节点名称前缀，例如「直连丨Xray-TLS」。

证书配置

当前选中的直连协议需要证书（Reality、VLESS + TCP、Shadowsocks 不需要证书）。

自签名证书有效期 10 年，无需续期。

ACME 自动申请：域名须解析到 VPS，端口 80 须放行；申请失败自动回退自签名。
证书状态：加载中…

当前选中的协议不需要证书，无需配置。

Reality 配置

publicKey 与 shortId 自动生成并保存在 reality.json，无需填写。

隧道配置

隧道节点名称前缀，例如「Argo丨Xray丨xhttp_h2」。

Zero Trust 里要加路由：Xray 域名 → 127.0.0.1:Xray 回源端口；Sing-box 域名 → 127.0.0.1:Sing-box 回源端口；订阅域名 → 127.0.0.1:订阅端口。

④ 节点与订阅

一个 UUID 通用于隧道和直连全部协议，订阅地址也只用这一个 UUID；不需要每个方式各设一个。节点名称前缀在③配置参数里按隧道 / 直连分别设置。

https://订阅域名//raw/UUID

订阅地址形如 https://订阅域名/订阅路径/raw/UUID。改这里，下次部署生效；已部署的可在「订阅地址」页直接改。订阅路径只能是字母 / 数字 / . _ -（1–32 个字符），不能是 api / config.json / help.txt。

⑤ 开始部署

只保存配置：只保存配置，不部署。
开始部署：保存配置并开始部署。
清除部署：只删除节点容器和生成的配置文件，面板与已保存配置保留；如需连面板一起彻底清理，请在 VPS 上执行一键清理脚本 cleanup.sh。
